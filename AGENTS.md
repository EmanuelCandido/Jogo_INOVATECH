# Modelagem 3D

Por solicitação do usuário, use Blender MCP nas próximas criações e modificações de modelos 3D deste projeto.
Antes de editar, confirme a conexão e inspecione a cena. Salve os fontes `.blend` em `assets-source` e exporte os modelos utilizados pelo aplicativo para `public/assets/models`, seguindo as convenções existentes.
O servidor MCP está registrado no Codex como `blender`. No Blender 5.2, o complemento é `blender_mcp`; inicie a conexão no painel MCP da viewport quando necessário. Se as ferramentas ainda não aparecerem após a instalação, reinicie o Codex.
